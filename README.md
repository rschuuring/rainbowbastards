# Rainbow Bastards

Website voor aannemersbedrijf Rainbow Bastards (grapversie, testsite).

## Mappen en bestanden

| Wat | Waarvoor |
|---|---|
| `inhoud.js` | **Alle** teksten, bedrijfsgegevens, diensten en projecten |
| `fotos/` | **Alle** foto's |
| `*.html` | De pagina's (opbouw, hoef je niet aan te komen) |
| `site/` | Opmaak (`stijl.css`) en de code die de pagina's vult (`site.js`) |
